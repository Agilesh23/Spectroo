Spectroo User Guide

1. Acquiring Spectra

  • Single Capture: Acquires a single snapshot of the spectrum at the current exposure time.
  • Live Stream: Continuously captures and plots the spectrum in real time. Ideal for laser alignment or observing real-time fluctuations.
  • Exposure Settings: Adjusts the camera's sensor exposure time in microseconds. Increase exposure to capture faint signals, or decrease it if peaks are clipping at the top.
  • Dark Frame Subtraction: Subtracts background thermal noise. Cover the sensor completely to capture a dark frame, and toggle dark subtraction to improve signal quality.

2. Toolbar Controls

  • Baseline Correction: Automatically identifies and subtracts slow-moving signal offsets, pinning the base of your peaks to zero.
  • Colour Spectrum: Overlays a visual colored ribbon matching the calibrated wavelengths (violet to red) across the spectrum plot.
  • Show Crosshair: Displays exact Wavelength/Pixel and Intensity values under your cursor for precise manual measurement.
  • History Panel: Restores previous captures, deletes obsolete ones, and exports records to JSON or CSV formats.

3. Analysis Operations

  • Peak Detection: Automatically tags local intensity peaks with their corresponding coordinate values.
  • Smoothing: Reduces high-frequency electronic noise, rendering a cleaner line without affecting raw peak locations.
  • Normalize: Scales the spectrum's intensity range using min-max scaling, shifting the minimum values to 0 and scaling the highest peak to 1.0 (or 100%). This allows easy comparison between spectra taken at different exposures.
  • Integrate (AUC): Computes the Area Under the Curve. Click and drag on the plot to select boundaries.

4. Wavelength Calibration Wizard

Wavelength calibration maps the camera's raw pixel indices to physical wavelengths in nanometers (nm).

  1. Click Wavelength Calibration in the menu to open the wizard.
  2. Identify a peak with a known physical wavelength (e.g., from a neon calibration lamp).
  3. Click the peak on the plot, select its marker, and enter the known wavelength (in nm).
  4. Repeat for at least two peaks across the spectrum.
  5. Click Fit Calibration to calculate the mapping (Residual RMS error is displayed).
  6. Click Apply Calibration to save it permanently to the device's settings (so that it persists even after a reboot).

5. Spectrum Comparison & Ratio

Compares the active spectrum against a reference to measure relative transmittance, absorption, or changes.

  1. Set a reference spectrum: either click Set as Ref on a saved capture in the History panel, or open the Comparison page and click Set Current as Reference.
  2. Click Compute Ratio on the comparison page.
  3. The plot will display Ratio = Current Intensity / Reference Intensity. Reference values near zero are safely ignored.

6. Basic Troubleshooting

  • Flat or Zero Signal: Check that the device is powered on, the lens cap is removed, and exposure is set above zero.
  • Flat-Topped Peaks: The sensor is saturated. Lower the exposure time or insert an optical attenuator.
  • No peaks detected: Ensure peak detection is enabled, and adjust exposure or peak parameters if needed.
  • Mismatched ratio sizes: Ensure the calibration has not changed between setting the reference and taking the current spectrum.
